# Cantina Fiesta Patronal — Android

Aplicación Android exclusiva para **Cantina → Venta de producto** del Sistema Fiesta Patronal San Francisco de Asís V3.4.2 RED.

La notebook continúa siendo el servidor principal y mantiene la base SQLite. La APK se conecta por Wi‑Fi/LAN al servidor y todas las ventas actualizan el mismo stock, informe, arqueo y numeración de tickets.
